BCR Headless 1.1.0-test.14

- Added a recorder mode selector so users can explicitly choose Stereo or Mono fallback while still seeing the VOICE_CALL capability probe result
- Updated Prepare Components to offer Stereo or Mono fallback preparation and download only the component set needed for that path
- Made transcriber readiness and component estimates follow the active recorder mode so the UI no longer implies the wrong model set is required
- Marked non-selected transcriber models as optional instead of failed or missing during the opposite preparation path
