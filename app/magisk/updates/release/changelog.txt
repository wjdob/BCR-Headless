BCR Headless 1.1.0-test.13

- Made stereo call capture the default recorder behavior, while still falling back to mono automatically when the ROM rejects stereo VOICE_CALL input
- Simplified the transcriber settings with language and model pick lists, optional advanced overrides, and a friendlier local whisper.cpp package override
- Added automatic queueing for new recordings, plus optional charging-only auto-start with a delay and clean restart-on-power-loss handling for transcript integrity
- Expanded queue cards to show started/completed timestamps and improved long filename wrapping in the Recordings and Queue views

Full project changelog: https://github.com/wjdob/BCR-Headless-Test/blob/v1.1.0-test.13/CHANGELOG.md
